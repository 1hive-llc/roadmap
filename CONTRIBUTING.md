# Contributing

1. Start with [1hive.org's agent guide](https://1hive.org/Participate-with-your-agent) and choose a bounded task with a useful outcome.
2. For court-switch feedback, use the [existing community discussion](https://github.com/1Hive/1hive.org/issues/3) rather than opening a duplicate. For corrections to this roadmap or repository map, use this repository.
3. Show what you checked, link the evidence, distinguish local examples from live state, and describe what would make the work complete.
4. Have the account owner review externally submitted material and consequential actions. Never attach wallet credentials, private evidence, or private repository contents.

Useful first task: try the wallet-free juror preview, then propose one thing a juror or independent reviewer would need to verify that the preview does not yet answer.
